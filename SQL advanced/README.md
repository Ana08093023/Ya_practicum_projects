# Описание проекта

## Цели проекта

Проект состоит из двух частей:

1. **Практическая часть**: Решение задач в SQL-тренажёре для закрепления пройденного материала.
2. **Аналитическая часть**: Самостоятельный анализ полученных результатов с формулированием выводов. Проверка задач по-прежнему будет выполняться тренажёром.

## Задачи

В ходе проекта вы столкнетесь с формулировками, приближенными к реальной жизни, такими как:
- Рассчитать LTV за последние 30 дней.
- Отобразить самых активных покупателей.
- Определить, почему в компании упали продажи.

## Данные

В проекте вы будете работать с базой данных **StackOverflow** — сервиса вопросов и ответов о программировании. База данных содержит информацию о постах за 2008 год, а также данные о более поздних оценках.

### Структура базы данных

**Таблицы:**

1. **stackoverflow.badges**
   - Хранит информацию о значках, присуждаемых за достижения.
   - Поля:
     - `id`: Идентификатор значка (первичный ключ)
     - `name`: Название значка
     - `user_id`: Идентификатор пользователя (внешний ключ к таблице users)
     - `creation_date`: Дата присвоения значка

2. **stackoverflow.post_types**
   - Содержит информацию о типах постов (Question и Answer).
   - Поля:
     - `id`: Идентификатор типа поста (первичный ключ)
     - `type`: Тип поста

3. **stackoverflow.posts**
   - Содержит информацию о постах.
   - Поля:
     - `id`: Идентификатор поста (первичный ключ)
     - `title`: Заголовок поста
     - `creation_date`: Дата создания поста
     - `favorites_count`: Число добавлений в «Закладки»
     - `last_activity_date`: Дата последнего действия
     - `last_edit_date`: Дата последнего изменения
     - `user_id`: Идентификатор пользователя (внешний ключ к таблице users)
     - `parent_id`: Идентификатор поста с вопросом (если есть)
     - `post_type_id`: Идентификатор типа поста (внешний ключ к таблице post_types)
     - `score`: Количество очков
     - `views_count`: Количество просмотров

4. **stackoverflow.users**
   - Содержит информацию о пользователях.
   - Поля:
     - `id`: Идентификатор пользователя (первичный ключ)
     - `creation_date`: Дата регистрации
     - `display_name`: Имя пользователя
     - `last_access_date`: Дата последнего входа
     - `location`: Местоположение
     - `reputation`: Очки репутации
     - `views`: Число просмотров профиля

5. **stackoverflow.vote_types**
   - Содержит информацию о типах голосов.
   - Поля:
     - `id`: Идентификатор типа голоса (первичный ключ)
     - `name`: Название метки

6. **stackoverflow.votes**
   - Содержит информацию о голосах за посты.
   - Поля:
     - `id`: Идентификатор голоса (первичный ключ)
     - `post_id`: Идентификатор поста (внешний ключ к таблице posts)
     - `user_id`: Идентификатор пользователя (внешний ключ к таблице users)
     - `bounty_amount`: Сумма вознаграждения
     - `vote_type_id`: Идентификатор типа голоса (внешний ключ к таблице vote_types)
     - `creation_date`: Дата назначения голоса
